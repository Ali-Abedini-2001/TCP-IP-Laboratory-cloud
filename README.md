# Network Lab - University of Tehran

This repository contains the materials for the **Network Lab course** at the University of Tehran.

The lab exercises are based on the **TCP/IP Essentials** book, with all chapters updated to work with modern tools on the **PNETLab simulator**.

The **modern version** of this lab exercises is available [here](https://github.com/HPNL/TCP-IP-Laboratory-cloud/tree/modern-version).
